# Update a record

Read `card <entity> <ref>` first. Use `node scripts/production.mjs set <entity> <ref> --field=value`, then read the card again. The CLI only accepts known fields. Every change is audited. Use `--day=null` to unschedule a scene. Add controls and an owner before marking a risk controlled. This records a person's decision, it does not make one for them. Never delete history.
