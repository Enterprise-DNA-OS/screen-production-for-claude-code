# Weekly production review

Run these three commands and read all their output:

1. `node scripts/production.mjs shoot-week --json`
2. `node scripts/production.mjs attention --json`
3. `node scripts/production.mjs wrap-report --json`

Report the next shoot, the missing cast or controls, and the scenes still unshot. Identify the owner from records, or say owner not recorded. Use `/draft-weekly-review` to save the review. Never invent explanations for missed scenes.
