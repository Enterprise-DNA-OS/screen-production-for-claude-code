# Why this base has no front end

The production office asks for tomorrow's calls, cast coverage and missing permissions in plain language. The agent runs one CLI against records the company owns. Static HTML gives the team a printable view without a web service.

A mobile crew portal gives each person their own login, push messages, read receipts and access away from the office. A stripboard supports drag-and-drop scheduling. A live broadcast rundown follows timing changes in real time. This base does none of those things. It also does not edit scripts, store video, optimise a schedule, calculate payroll or send a call sheet.

The useful unit here is the office record: a scene, a booking, an hours entry, a risk control and the evidence behind it. Enterprise DNA can add the screen or connections a production actually needs as custom work. Keep media in its existing store and retain links to the source.

One trusted office runs the CLI. Postgres can hold shared records, but a shared owner account is not individual crew access control. PGlite is for one local process at a time. The free base has no offline synchronisation. Review the roster and output before distributing any document.
